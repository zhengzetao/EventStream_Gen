# Examples

This directory contains tiny illustrative examples for GitHub readers.

- sample_skeleton_semantic_qa.json shows one generic uncalibrated sample and one Taxi-Pro calibrated sample.
- The examples include skeleton/mechanism fields, event samples, semantic wrapping, ground-truth-derived QA, validation summaries, and calibration metadata.
- Full generated datasets, calibration priors, prepared CSVs, raw datasets, LLM caches, and training JSONL outputs are intentionally not committed to GitHub.
